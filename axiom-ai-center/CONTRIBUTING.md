# Contributing to the center website

Center members can propose updates through GitHub without needing to edit the whole site.

## Update your own profile

1. Sign in to GitHub and open your file inside the `people` folder.
2. Select the pencil icon to edit.
3. Change only your biography, links, publications, teaching, office, and topic tags.
4. Choose **Create a new branch for this commit and start a pull request**.
5. Add a short summary of the change and request review from the site maintainer.

Do not change shared files such as `assets/css/styles.css` or `assets/js/main.js` as part of a profile-only update.

## Add news or publications

Edit `news.html` or `publications.html`, copy an existing entry, and replace its content. Keep dates in ISO format inside the `datetime` attribute.

## Review checklist

- Links work and use `https://` where appropriate.
- Claims, dates, affiliations, and publication details are accurate.
- Images have useful alternative text if images are added later.
- The page reads well on both a phone and a desktop browser.
